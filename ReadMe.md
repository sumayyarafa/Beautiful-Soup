# Web Scraping with Beautiful Soup 🕸️

##  About This Repository

This repository contains my learning materials, Python code, and practical exercises related to **Web Scraping using Beautiful Soup**.

The purpose of this repository is to learn how to extract, parse, and organize data from websites using Python. 


##  Technologies & Libraries

- **Programming Language:** Python
- **Web Scraping Library:** Beautiful Soup 4
- **HTTP Library:** Requests
- **HTML Parser:** HTML Parser
- **IDE:** Visual Studio Code / PyCharm
- **Version Control:** Git and GitHub

##  Installation

Install the required Python libraries:

```bash
pip install beautifulsoup4 requests
```

##  How to Run

**1. Clone the repository**

```bash
git clone <your-repository-url>
```

**2. Navigate to the project folder**

```bash
cd BeautifulSoup
```

**3. Run a Python file**

```bash
python filename.py
```
